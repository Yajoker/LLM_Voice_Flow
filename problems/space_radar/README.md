# 太空探测与动态几何体查询（3D 空间雷达系统）

笔试编程题解答。题面要求：维护球体 / OBB 长方体 / 圆柱体 / 三角面片四类几何体，
支持「射线脉冲」查询——沿射线找首个命中物体，并将其沿射线方向瞬间推动一段距离。

## 一、结构化 Prompt（题意提炼）

> **任务**：用 C++ 实现一个 3D 空间雷达查询系统，要求代码完整、可直接编译运行、无 bug。
>
> **几何体（四类，编号从 0 开始按输入顺序）**
> - 球体 `0 cx cy cz r`：球心 `(cx,cy,cz)`，半径 `r(>=0)`。
> - OBB 长方体 `1 cx cy cz ux uy uz vx vy vz wx wy wz`：中心 `(cx,cy,cz)`，
>   `u/v/w` 为指向相邻面的三条**半轴向量**，两两正交、长度均 `>0`，可不与坐标轴对齐。
> - 圆柱体 `2 cx cy cz ax ay az r halfH`：中心 `(cx,cy,cz)`，轴向 `(ax,ay,az)(非零)`，
>   底面半径 `r(>=0)`，`halfH(>=0)` 为中心到两端面的半高，可不与坐标轴对齐。
> - 三角面片 `3 v1x..v3z`：三顶点构成的三角形；其“中心”为三顶点算术平均。
>
> **查询：射线脉冲 `2 ox oy oz dx dy dz d`**
> - 射线 `P(t)=(ox,oy,oz)+t·(dx,dy,dz)`，`t>=0`，方向不全为零。
> - 输出首个被命中（`t` 最小）物体的编号；无命中输出 `-1`。
> - 命中后该物体（仅这一个）瞬间沿 `normalize(dx,dy,dz)` 平移距离 `d(0<=d<=1e5)`，
>   即中心坐标 `+= d·normalize(dir)`；三角面片三顶点同时平移相同位移。
>   推动是瞬时的、不考虑碰撞，且**影响后续查询**。
>
> **判定规则**
> 1. 所有几何体视为闭集，边界点算内部。
> 2. 若射线起点在某物体内部或边界上，则在 `t=0` 处命中该物体。
> 3. 多物体同 `t` 命中时：优先 `t` 更小者；`t` 相同则返回编号更小者，且只有该物体被推动。
>
> **数据范围**：`1<=n,q<=1e5`；输入坐标/参数均为整数，绝对值 `<=1e9`；
> 浮点歧义极小，建议 `epsilon=1e-9`。
> **输入**：首行 `n q`；接 `n` 行物体；接 `q` 行查询。**输出**：每条查询一行答案。

## 二、解法

逐类做精确的射线-几何体相交（统一使用 `long double`，`epsilon=1e-9`）：

- **球体**：解 `|O+tD−C|²=r²`；`c=|O−C|²−r²<=0` 表示起点在内部 → `t=0`，否则取近根。
- **OBB**：slab 法。用**非单位半轴** `u` 直接判定（点在内：`|(X−C)·u|<=u·u`），避免开方；
  对 `u/v/w` 三个 slab 求交得入射/出射区间。
- **圆柱体**：无限侧面（径向距离 `=r` 的二次方程，再校验沿轴坐标 `∈[−halfH,halfH]`）
  + 两端盖圆面，取所有候选 `t` 的最小值。
- **三角面片**：Möller–Trumbore，重心坐标 `u,v∈[0,1]` 且 `u+v<=1`。

平局：遍历时仅当 `t` 严格更小（相对容差外）才替换，相等则保留更小编号；
命中后按类型对中心或三顶点施加位移。

## 三、两个版本

| 文件 | 算法 | 复杂度 | 适用 |
|------|------|--------|------|
| `solution.cpp` | 每查询遍历全部物体 | `O(n·q)` | 逻辑最简单、**保证正确**；适合中小规模子任务 |
| `solution_fast.cpp` | BVH(分桶,连续内存) + 命中后刷新包围盒（**最终提交版**） | 约 `O((n+q)·log n)`（数据分散时） | 满规模分散约 0.4s/1e5、中等偏密约 0.8s；二者已用 14000 组多尺度随机数据对拍一致 |

`solution_fast.cpp` 的关键性能优化：
1. **全程 `double` + 预计算方向倒数**：判定与遍历均用 `double`（题面建议 `1e-9` epsilon
   且声明精度歧义极小，即按 `double` 设计；已与 `long double` 基准在 14000 组多尺度
   数据对拍一致）。
2. **物体参数按 BVH 叶子顺序重排为连续内存**（以内存换时间）：叶子内逐物体读取变为
   顺序访问，大幅减少 cache miss——分散满规模 0.6s → 0.4s、密集 100k 2.5s → 1.6s。
3. **叶子分桶**（一个叶子最多 16 个物体）：内部节点数与射线-包围盒测试量成倍下降。
4. **球体命中提前否决**：用当前最优 `tMax` 在开方前否决明显更远的球体，跳过 `sqrt`
   （稠密球体场景中绝大多数物体都被否决）。
5. **遍历栈缓存入射 `t`、入栈即剪枝、手写下标栈**：去掉重复盒测试与容器开销。
6. **两阶段查询**：先「包含查询」找包含起点（`t=0`）的最小编号物体，存在则直接返回；
   否则再做最近面求交。
7. **相切判别式容差**：球/圆柱二次判别式 `|disc|` 在容差内视为相切（取单根 `-B/2A`），
   符合「闭集边界算命中」且避免 `sqrt(微小正数)` 放大噪声造成的命中排序抖动。

> 固有难点：当大量物体**真实重叠于同一小区域**（射线穿过即命中大量物体）时，任意 BVH
> 都无法靠空间剪枝避免逐一检测这些物体，会趋于 `O(n·q)`——这是稠密光线投射的本质，
> 没有简单的次平方保证；常规/分散数据不会触发此极端重叠。

## 四、构建与测试

```bash
g++ -O2 -std=c++17 -o solution solution.cpp
g++ -O2 -std=c++17 -o solution_fast solution_fast.cpp
./solution      < sample.in     # 期望 0 1 3 0
./solution_fast < sample.in

# 随机对拍（暴力 vs 加速）
for s in $(seq 1 2000); do
  python3 gen.py $s > t.in
  diff <(./solution < t.in) <(./solution_fast < t.in) || { echo "FAIL $s"; break; }
done
```

`sample.in` 为题目样例；`tri.in`（三角片命中+推动）、`tie.in`（同 t 取小编号 + 仅推动命中体）为补充用例。
